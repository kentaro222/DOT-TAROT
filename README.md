# PIXEL TAROT — improved build

主な変更:
- 不正な二重 `<head>` を修正
- 問い入力と3種類の3枚スプレッドを追加
- 結果をカードをめくるまで隠すUXに変更
- 「すべてめくる」操作を追加
- 1bitカードに合わせてUIを角形・ハードシャドウ中心に統一
- 図鑑カードを `button` 化し、キーボード操作・ARIAを改善
- 図鑑に前後ナビゲーションを追加
- `innerHTML` によるカード本文挿入を廃止
- PWA manifest / Service Workerを更新
- 192/512px・Apple Touch iconを既存スプライトから生成
- 「節制」の「調推」を「調和」に修正

ローカル確認時は Service Worker のため、HTTPサーバー経由で開いてください。例: `python -m http.server 8000`


## v2 fixes
- カードスプライトの右端・下端が欠ける問題を修正（`box-sizing: content-box` とサムネイル計算の補正）
- 逆位置カードが一瞬正位置に見える問題を修正（逆位置専用フリップアニメーション）
- 占い結果に影響しない「願いごと／問い」入力欄を削除
- Service Worker のキャッシュを v3 に更新
